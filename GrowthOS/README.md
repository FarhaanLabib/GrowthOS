How to run this project : 
1. Clone and install : Commands below ->
git clone https://github.com/FarhaanLabib/GrowthOS.git
cd GrowthOS
npm install
cd frontend
npm install
cd ..
2. Create a .env file :
MONGO_URI=ask a team member for this
DB_NAME=growthos
PORT=5000
3. Run it :
Open two terminals.
First terminal command ->
node server.js
Another terminal ->
cd frontend
npm run dev
4. Open the app :
Go to http://localhost:5173 in your browser.
